# AIOps Control Plane

Production-grade systems engineering and automation control plane hosted on `lab-host` (Ubuntu 26.04 LTS).

## Project Overview
- **Hardware Engine:** `lab-host` (Remote Tailscale Node)
- **Core Stack:** Linux Architecture, Systemd Daemons, Docker Compose, FastAPI Telemetry Engine, Local AI Models (Ollama)

## Structure
- `/docs/curriculum/` - Master multi-month execution curriculum and daily milestones.
- `/docs/logs/` - Daily build logs and operational proof-of-work documentation.
- `/scripts/` - Automation scripts and systemd unit configurations.
